The Logic

Problem: A product with one 5-star rating looks "better" than a product with one hundred 4.8-star ratings.

def calculate_average(ratings):
    if not ratings:
        return 0
    
    total = sum(ratings)
    count = len(ratings)
    
    return total / count

Time-Decay Rating

Ratings become less relevant as time passes. Essential for "Trending" feeds.

Uber Driver Score

Formula: Exponential Decay

Score = Initial Rating × e(-λ × time)

Where λ (decay rate) = 0.1

Implementation

import math

def calculate_decay(rating, days_ago):
    # Decay rate (lambda)
    decay_rate = 0.1 
    
    # Calculate weight factor
    weight = math.exp(-decay_rate * days_ago)
    
    return rating * weight
